# RAENKO landing

Статическая витрина для направления AI-автоматизации и безопасности рабочих инструментов и интеграций.

## Структура

```text
/index.html
/assets/styles.css
/assets/main.js
/assets/scene.js        — собранная WebGL-сцена первого экрана (не править вручную)
/tools/scene/          — исходники сцены и сборка (three.js + esbuild), на деплой не влияют
/vercel.json
/robots.txt
/sitemap.xml
```

## Принципы

- `main` не менять без отдельного подтверждения.
- Рабочая ветка редизайна: `redesign`.
- Без серверной логики, cookies, localStorage и внешних API-запросов.
- Контакты ведут напрямую в Telegram и email.
- Security headers описаны в `vercel.json`.

## Проверка перед публикацией

1. Открыть сайт локально через обычный static server.
2. Проверить мобильную версию.
3. Проверить клики по Telegram и email.
4. Проверить заголовки после деплоя на Vercel.
5. Проверить, не остаётся ли `x-robots-tag: noindex` на production-домене.

## Сцена первого экрана

- Источник: `tools/scene/src/`. Сборка: `cd tools/scene && npm install && npm run build` — результат пишется в `assets/scene.js`, его нужно коммитить (Vercel собирает проект как статику, без шага сборки).
- Тесты логики и запасного режима: `npm test` в `tools/scene`.
- Камера не используется. Управление: мышь на десктопе, наклон на телефоне.
- Запасной режим: нет WebGL — остаётся CSS-фон; `prefers-reduced-motion` — один статичный кадр; медленное устройство — разрешение снижается, затем кадр замораживается.
- Заголовок, текст и кнопки первого экрана остаются обычным HTML поверх canvas.
